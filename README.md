**Focus Guardian WebLock**
Focus Guardian WebLock is a productivity and parental control tool that lets parents or users block distracting websites directly from the browser. It consists of two parts: a Chrome Manifest V3 extension that intercepts and blocks configured URLs in real time, and a React/TypeScript dashboard backed by Supabase for managing blocked sites, schedules, and user settings.

**Features:**
Block any website by domain with a single click
Manage blocklists from a clean, responsive dashboard
Real-time sync between the extension and dashboard via Supabase
Parental control mode — changes can be password-protected
Built with Chrome Manifest V3, React, TypeScript, Tailwind CSS, and Vite

**Tech Stack**
React , TypeScript , Supabase , Tailwind CSS , Vite , Chrome Extensions (MV3)

**Purpose**
Originally developed as a Software Requirement Engineering project at Pak-Austria Fachhochschule, this tool addresses real-world productivity and child safety needs with a practical, deployable solution.

# WebLock Extension

A drop-in Chrome/Edge/Brave extension that blocks distracting websites.

## Two modes

- **Local** (default): Manage your own blocklist from the popup.
- **Cloud**: Pair with your WebLock dashboard. Blocking, focus mode, and schedules are controlled remotely.

## Install

1. Download `weblock-extension.zip` from your dashboard and unzip it.
2. Open `chrome://extensions` (works in Chrome, Edge, Brave, Arc, Opera).
3. Toggle **Developer mode** on (top-right).
4. Click **Load unpacked** and pick the unzipped `weblock-extension` folder.
5. Pin the WebLock icon to your toolbar.

## Pair with WebLock Cloud

1. In your dashboard → **Devices** → **Pair device** → copy the 6-digit code.
2. Click the WebLock icon → **Pair with WebLock Cloud** (opens pair tab).
3. Enter the code → done. The popup switches to Cloud mode automatically.

To unpair, open the popup → **Unpair this device**.
